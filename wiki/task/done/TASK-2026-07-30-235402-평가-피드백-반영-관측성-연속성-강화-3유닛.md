## 개요

세션 이동성(재개 인덱스), 토큰 비용 관측(null-not-0), 세션 호핑 상태 집계(read-only cockpit)를 각각 studio/task-worker/studio에 추가한다. negative trigger 문서는 root closeout에 흡수.

## 근거

스위트 평가 결론: 최우선 가치(stateless+보존성, 토큰 효율) 대비 studio 연속성 부재와 계측 0이 최대 갭. challenge review 1라운드 통과(blocking 3건 반영: NEGTRIG 리프 삭제, pytest.ini 선행, receipt는 supersede DEC로 해소).

## 범위와 완료 기준

리프 3개 병렬(RECEIPT/TELEMETRY/COCKPIT) + root closeout(negtrig 문서, 버전 bump). 완료 = 각 리프 검증 anchor green + refresh integrity strict 통과.
